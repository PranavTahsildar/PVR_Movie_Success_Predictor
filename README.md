# PVR Technologies
## Movie Success Rate Predictor

### Project Overview

The Movie Success Rate Predictor is a machine learning
application developed to predict whether a movie is likely
to achieve a successful outcome based on historical movie data.

### Features

- Machine learning prediction
- Tuned model
- Streamlit dashboard
- SHAP explainability
- Model performance metrics
- Data drift monitoring
- Responsible AI documentation
